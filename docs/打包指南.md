# DSTranslator 打包指南

改了代码后,重新生成 `dist\DSTranslator\` 绿色版的完整流程。面向开发者本人。

## 0. 一句话流程

```
.venv\Scripts\pyinstaller --noconfirm --clean DSTranslator.spec
copy docs\使用说明.md dist\DSTranslator\使用说明.md
```

产物:`dist\DSTranslator\`(one-folder + windowed,无控制台,自带 Python 运行时,目标机无需装 Python)。

---

## 1. 前置条件

- 在**项目根目录**执行,使用 `.venv`(Python 3.12,基于 Anaconda `markitdown` 环境创建)。
- `.venv` 已装有 `pyinstaller`、`pillow`(如缺:`pip install pyinstaller pillow`)。
- 需要这些文件:
  - `DSTranslator.spec` —— 打包配置(入口、conda 运行库、pynput 收集)
  - `dstl.ico` —— 程序图标
  - `tools/make_icon.py` —— 需要换图标时重新生成(可选)

## 2. 打包命令

```bash
cd F:\agent-project\ClaudeCode\DSTranslator
.venv\Scripts\pyinstaller --noconfirm --clean DSTranslator.spec
```

`--clean` 清掉缓存、`--noconfirm` 覆盖旧产物。首次约 1 分钟,之后更快(会重建 `build\` 缓存,不用手动删)。

## 3. 打包后必做

```bash
copy docs\使用说明.md dist\DSTranslator\使用说明.md
```

**原因**:重建会清空 `dist\DSTranslator\`,而 `使用说明.md` 没打进包里,需要手动拷回。忘拷不影响程序运行,但分发的包里会缺说明书。

**分发干净版(可选)**:如果不想把本机数据(加密的 API key、历史)带给别人,删掉 `dist\DSTranslator\data\` 再拷贝。删了会在对方设备首启时自动重建(需对方输入自己的 key)。

## 4. 打包为什么长这样(spec 要点)

| 配置 | 原因 |
|---|---|
| 入口 `src/main.py` + `pathex=['src']` | 源码在 `src/` 下,`dstl` 包要靠它找到 |
| `CONDA_BIN` 下全部 `*.dll` 打进 `_internal` | **conda Python 的扩展模块**(`_ctypes`、`_sqlite3`、`_hashlib` 等)链接的是 `Library\bin` 里的 `ffi.dll`、`sqlite3.dll`、`libcrypto` 等;PyInstaller 依赖扫描会漏,不带上就报 `DLL load failed` |
| `collect_all('pynput')` | pynput 平台后端是动态导入的,PyInstaller 默认收集不全 |
| `console=False` | 无控制台窗口的 GUI 程序 |
| `icon=['dstl.ico']` | 程序图标 |

**⚠ 换 conda 环境 / 换 Python 时**:必须同步改 spec 里的 `CONDA_BIN` 路径,否则缺 DLL 起不来。

## 5. 验证打包结果

1. 双击 `dist\DSTranslator\DSTranslator.exe`,应无报错,且自动生成 `data\`(config.json、history.db)。
2. 任意应用里选中文字 `Ctrl+C` → 弹窗自动翻译 → `data\history.db` 出现记录。
3. `Ctrl+Alt+S` 空召、托盘图标正常。
4. 首次运行弹 SmartScreen「未知发布者」属正常(未签名),点「仍要运行」。

> 打包 exe 无控制台,它的 print 日志会被丢弃;若启动即闪退,用命令行直接跑 `dist\DSTranslator\DSTranslator.exe` 看不到报错,需回看 CHANGELOG v0.5.0 的排查记录。

## 6. 常见打包报错

| 报错 | 原因 / 处理 |
|---|---|
| `DLL load failed while importing _ctypes / _sqlite3 / ...` | conda 运行库没带上 → 检查 spec 的 `CONDA_BIN` 是否正确、`Library\bin` 是否存在 |
| pynput 相关 `ImportError`(此平台不受支持) | `collect_all('pynput')` 缺失或失效 |
| 改了源码但打包后行为没变 | 忘了 `--clean`(缓存)或打包的不是改动后的入口 |

## 7. 关键文件清单

| 文件 | 作用 |
|---|---|
| `src/main.py` | 程序入口 |
| `src/dstl/` | 应用源码 |
| `DSTranslator.spec` | 打包配置(唯一需要随环境调整的文件) |
| `dstl.ico` | 图标 |
| `tools/make_icon.py` | 重新生成图标 |
| `docs/使用说明.md` | 用户说明书,打包后拷进 `dist\DSTranslator\` |
| `dist\DSTranslator\` | 最终绿色版交付物 |
