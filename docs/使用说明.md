# DSTranslator 使用说明

一个 DeepSeek 驱动的翻译 / 解释悬浮窗工具。浏览网页或读 PDF 时,选中文字复制一下,就能立刻看到翻译或释义,不用切换应用。

---

## 1. 这是什么

- **翻译**:把其他语言(主要是英文)翻译成中文,默认功能。
- **解释**:查词典 + 百科式释义(含义、语境、用法),适合看不懂的术语。
- 两者都由你提供的 **DeepSeek API key** 驱动,默认不联网搜索。

## 2. 系统要求与快速开始

- **仅支持 Windows 10 / 11**,**不需要安装 Python**(已自带运行环境)。
- 双击 `DSTranslator.exe` 启动,程序常驻系统托盘。
- **首次使用**:会弹出「配置 API key」对话框,粘贴你的 DeepSeek API key 并保存。
  - 没有 key?去 [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) 创建。

## 3. 日常使用

| 操作 | 方法 |
|---|---|
| **翻译** | 在任意应用中选中文字,**快速连按两次 `Ctrl+C`(双击)**,弹窗自动出现在屏幕顶部并自动翻译 |
| **普通复制(不触发)** | 单击 `Ctrl+C` 只复制到剪贴板,**不会**弹窗 |
| **唤起空弹窗** | 按 `Ctrl+Alt+S`,或双击托盘图标(手动粘贴/输入内容用) |
| **查释义** | 点「解释」tab;面板里的「深度解释」「联网解释」两个开关可叠加使用 |
| **关闭弹窗** | 按 `Esc`(可在快捷键设置里改),或点顶栏 `×` |
| **暂停 / 恢复捕获** | 右键托盘取消勾选「启用捕获」(或在快捷键设置顶部关掉开关):关闭后复制与唤起键都不弹窗,托盘手动调出仍可用 |

- 弹窗消失方式在 ⚙ 设置里配置:**固定驻留**(不自动关,点 ×/Esc 关)或**自动**(N 秒无操作自动收起,秒数可改)。
- 捕获关闭时托盘图标变灰、悬停显示「捕获已暂停」;再次勾选即恢复。

## 4. 设置(⚙ 菜单)

- **弹窗消失**:固定驻留 / 自动 · N 秒(秒数可编辑,1–600)。
- **快捷键设置**(⚙ → 快捷键设置):
  - 顶部状态条:显示当前捕获状态(「● 捕获中 · 双击 Ctrl+C 翻译」/「捕获已暂停」),内置「启用捕获」开关,与托盘勾选联动;**点「完成」生效,「取消」丢弃**。
  - 「唤起搜索栏」「复制触发键」「关闭搜索栏」三个按键可改(点「更改」后直接按下新组合键)。
  - 复制触发键默认 `Ctrl+C` **双击**触发;改成其他组合键后**单击**触发。
- **开机自启**:可选。
- **历史记录**:查看/搜索/删除/复制/导出之前的翻译与解释记录。
- **配置 API key**:更换或重新输入 key。
- **退出**:退出程序(缩到托盘时不是退出)。

## 5. 便携与数据

- 所有数据(config、**加密的** API key、历史记录)都存在 **exe 旁边的 `data\` 文件夹**里。
- **拷走整个文件夹 = 换设备后数据一起带走**(key 和历史都在),无需重新配置。
- 删掉 `data\` 文件夹:下次启动会自动重建,但 **API key 需要重新输入一次**、历史清空。
- API key 使用 Windows DPAPI 加密,只有当前 Windows 用户能解开,不会上传到别处。

## 6. 常见问题

- **首次运行弹 SmartScreen「未知发布者」警告**:正常现象(未签名软件),点「仍要运行」即可;杀软误报时加入白名单。
- **PDF 里有些文字选不中**:说明该控件不支持选择,手动 `Ctrl+C` 复制即可。
- **换设备后历史为空**:把旧设备的 `data\` 文件夹一起拷过来。
- **想恢复默认设置**:退出程序后,删除 `data\config.json`。
- **提示"未配置 API key"**:点 ⚙ →「配置 API key…」输入 key。
- **双击 `Ctrl+C` 没反应**:确认已选中文字、两次按下在约半秒内;若仍无效,看托盘图标是否变灰(捕获被暂停),或在快捷键设置里检查复制触发键是否被改过。

## 7. 已知限制

- 弹窗弹出时会**抢走当前应用的键盘焦点**(为了 Esc / 输入立即可用);连续查词时需点回阅读应用。
- 打包体积约 137MB(自带完整运行环境所致)。
