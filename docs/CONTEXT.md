# DSTranslator

一个 Windows 桌面工具:通过全局捕获用户在任意应用中选择的内容,借助 DeepSeek API 进行翻译与解释,全程不离开当前应用、不打断阅读节奏。翻译和解释均由用户提供的 DeepSeek API key 驱动。

## Language

**捕获 (Capture)**:
应用从用户当前所在应用截获内容的过程。用户无需切换应用即可触发。
_Avoid_: 复制、选择、取词

**捕获源 (Capture source)**:
捕获内容的两种底层来源:剪贴板(用户 Ctrl+C 后读取)或当前选中文本(热键/鼠标组合直接抓取)。
_Avoid_: —

**捕获模式 (Capture mode)**:
应用截获内容的方式:按下复制触发键(默认 Ctrl+C)触发,读取剪贴板内容。内容来源始终是剪贴板;触发通过按键识别,普通单次复制不会自动弹窗。
_Avoid_: 复制方式

**捕获开关 (Capture switch)**:
决定应用是否对触发自动响应的总开关。关闭时,复制触发键与唤起键都不会弹出搜索栏;从托盘手动调出仍可用。
_Avoid_: 暂停、静音、启用/禁用

**复制触发键 (Copy hotkey)**:
触发"带剪贴板内容弹出"的组合键,默认 Ctrl+C。默认值需双击触发;用户自定义的组合键单击即触发。
_Avoid_: 复制快捷键、复制键

**双击触发 (Double-tap trigger)**:
针对默认复制触发键 Ctrl+C 的规则:约半秒内连按两次才触发,使普通复制不受影响。
_Avoid_: 连按、双击复制

**翻译 (Translate)**:
将其他语言(主要为英文)的内容译为中文,由 DeepSeek 驱动。默认功能。
_Aavoid_: 译文、汉化

**解释 (Explain)**:
用中文对给定内容做词典+百科式释义(含义、语境、用法),由 DeepSeek 驱动。不做联网搜索。
_Avoid_: 搜索、查找、释义

**搜索记录 (History record)**:
一次成功捕获请求的本地记录:(源文本, 结果, 模式[翻译/解释], 时间戳)。失败的请求不保存。
_Avoid_: 历史、日志

**捕获触发的搜索栏 (Capture-triggered search bar)**:
应用的界面形态。平时隐藏但记住停放位置;任何捕获(剪贴板/热键/鼠标组合)使其在固定位置出现、填入内容并自动执行默认翻译,结果在下方展开;Esc 收起,另有全局热键可空召。
_Avoid_: 悬浮窗、弹窗、弹出窗

## 用户向用语 (User-facing terms)

对外文案(落地页、README 宣传语、推广内容)允许也应当使用用户语言,与内部术语一对一映射,两者不冲突。上文的 _Avoid_ 仅约束内部文档与代码,不约束对外文案。页面大标题优先用行为描述,避免堆术语。

| 内部术语 | 对外用语 | 说明 |
|---|---|---|
| 捕获触发的搜索栏 | 悬浮窗 | 对外一律称"悬浮窗" |
| 双击触发 | 双击 Ctrl+C | 触发方式的行为化表述 |
| 复制触发键 | 复制快捷键 | 自定义组合键的对外名称 |
| 捕获开关 | 一键暂停捕获 | 对外功能名 |
| 搜索记录 | 历史记录 | 对外 UI 与文案 |
| 捕获 (Capture) | 选中即触发 | 对外描述:选中文字,双击复制即弹窗 |
| 翻译 (Translate) | 翻译 | 同名;解决"这句话什么意思" |
| 解释 (Explain) | 解释 | 同名;主打场景:论文里遇到术语/名词,物理意义不清楚,选中即讲清它是什么 |
