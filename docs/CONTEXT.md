# DSTranslator

一个 Windows 桌面工具:通过全局捕获用户在任意应用中选择的内容,借助 DeepSeek API 进行翻译与解释,全程不离开当前应用、不打断阅读节奏。翻译和解释均由用户提供的 DeepSeek API key 驱动。

## Language

**捕获 (Capture)**:
应用从用户当前所在应用截获内容的过程。用户无需切换应用即可触发。
_Avoid_: 复制、选择、取词

**捕获源 (Capture source)**:
捕获内容的两种底层来源:剪贴板(用户 Ctrl+C 后读取)或当前选中文本(热键/鼠标组合直接抓取)。
_Avoid_: —

**捕获模式 (Capture mode)**:
应用截获内容的方式,唯一为剪贴板复制:用户在任意应用中 Ctrl+C 后,应用读取剪贴板内容。不采用全局热键/鼠标组合捕获,避免与其他应用冲突。
_Avoid_: 复制方式

**翻译 (Translate)**:
将其他语言(主要为英文)的内容译为中文,由 DeepSeek 驱动。默认功能。
_Aavoid_: 译文、汉化

**解释 (Explain)**:
用中文对给定内容做词典+百科式释义(含义、语境、用法),由 DeepSeek 驱动。不做联网搜索。
_Avoid_: 搜索、查找、释义

**搜索记录 (History record)**:
一次成功捕获请求的本地记录:(源文本, 结果, 模式[翻译/解释], 时间戳)。失败的请求不保存。
_Avoid_: 历史、日志

**捕获触发的搜索栏 (Capture-triggered search bar)**:
应用的界面形态。平时隐藏但记住停放位置;任何捕获(剪贴板/热键/鼠标组合)使其在固定位置出现、填入内容并自动执行默认翻译,结果在下方展开;Esc 收起,另有全局热键可空召。
_Avoid_: 悬浮窗、弹窗、弹出窗
