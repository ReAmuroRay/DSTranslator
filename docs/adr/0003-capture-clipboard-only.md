# 捕获仅剪贴板,Ctrl+C 为唯一触发

捕获方式收敛为唯一的剪贴板监听:用户在任意应用中 Ctrl+C 后,应用读取剪贴板内容触发翻译/解释。早期的全局热键抓取(Ctrl+Alt+T)与左键+右键鼠标组合捕获被移除。

曾权衡:热键/鼠标组合可"选中即翻译、不占用剪贴板",但热键组合常被网页/PDF 阅读器拦截,鼠标组合存在误触发风险,且修复冲突的成本高于收益。用户明确接受"必须真实 Ctrl+C(会占用剪贴板)"的代价,换取零冲突。全局唤起键(Ctrl+Alt+S)仍保留,只做"空召搜索栏",不参与捕获。

**Consequences**:无法对"选中但未复制"的文本直接翻译;唤起键是唯一剩余的全局钩子;剪贴板被占用是预期行为。
