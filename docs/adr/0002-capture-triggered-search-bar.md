# 界面形态:捕获触发的搜索栏

界面采用"捕获触发的搜索栏",而非 XTranslator 式的跟随鼠标弹出窗。

用户核心诉求是"浏览网页/读 PDF 时不切换应用、不打断节奏",且明确偏好搜索栏式的清晰布局(两栏:翻译/解释)。权衡过的选项:

- **A. 跟随鼠标的弹出窗**:结果总在目光所在处,但会盖住正在读的文本、频繁捕获时闪烁、长解释在小窗里局促。
- **B. 常驻搜索栏**:布局清楚,但永久占用屏幕空间。
- **C. 捕获触发的搜索栏**:平时隐藏零占用,捕获时在固定停放位置出现——兼顾两者。

选择了 **C**。三者共享同一窗口组件、仅锚点不同;若日后觉得目光移动成本高,可低成本新增"结果面板跟随鼠标"的选项,不推翻整体结构。

**Consequences**:捕获瞬间有一个"从无到有"的出现动画;搜索栏的停放位置成为用户需要配置的一项。
