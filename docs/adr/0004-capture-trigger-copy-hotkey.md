# 捕获触发演进:复制触发键(默认双击),内容仍读剪贴板

触发机制从"任意剪贴板变化即捕获"演进为"按下复制触发键才捕获":默认 `Ctrl+C` 需在约半秒内连按两次(双击触发)才弹出,避免劫持普通复制;用户在设置里改成的其他组合键则单击触发。捕获内容仍始终来自剪贴板,沿用 [0003](0003-capture-clipboard-only.md) 的内容决策,不改动。

为支持"复制触发键可配置"与"双击触发",在唤起键之外引入**第二个全局按键钩子**(pynput),这是对 ADR-0003"唤起键是唯一剩余全局钩子"的一次有意扩展。代价是普通单次复制不再自动翻译(需双击),换来复制触发键可定制、且不与普通复制冲突。

另设「捕获开关」总开关:关闭时复制触发键与唤起键都不弹窗,手动托盘调出仍可用。

**Consequences**:新增一个全局键盘钩子;单次复制不再触发;复制触发键成为设置项;捕获开关关闭时应用对自动触发完全静默。
